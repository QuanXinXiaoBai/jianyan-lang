# 【简言】编译器原型

一门**中文缩进式**教学编程语言 `简言` 的编译器原型，用 Rust 编写，后端输出
**NASM 语法的 x86-64 Windows 汇编**，配合 `nasm.exe` + `GoLink.exe` 完成
“源码 → 汇编 → COFF 目标文件 → exe” 的完整编译闭环。

> 学习向实现：代码清晰、模块化、注释齐全，不做性能优化。
> 零第三方 Rust 依赖、不依赖系统全局的 mingw / gcc / ld，便携性好。

---

## 一、快速上手

### 1. 环境准备

- **Rust 工具链**（构建编译器本身需要）：<https://rustup.rs/>，安装后 `cargo build` 即可。
- **汇编器 nasm.exe**：放到本项目 `./tools/` 目录。
  下载：<https://www.nasm.us/pub/nasm/releasebuilds/>（win64 压缩包内）。
- **链接器 GoLink.exe**：放到本项目 `./tools/` 目录。
  下载：<http://www.godevtool.com/>（`GoLink.zip`，解压得到单文件 `GoLink.exe`）。

工具查找顺序：`./tools/` → 编译器所在目录旁的 `tools/` → 系统 `PATH`。

### 2. 构建编译器

```powershell
cargo build --release
# 产物：target\release\jianyan.exe
```

### 3. 三种编译模式

| 模式 | 命令 | 产物 |
| ---- | ---- | ---- |
| A 仅输出汇编 | `jianyan -S demo.jy` | `demo.asm`（不调用 nasm、不链接） |
| B 完整构建 | `jianyan demo.jy` | `demo.asm → demo.obj → demo.exe`（成功后清理中间产物） |
| C 保留中间物 | `jianyan --keep-temp demo.jy` | 同上，但保留 `.asm` 与 `.obj` |

完整构建三步（模式B）：

```powershell
# ① 简言源码 → demo.asm（编译器生成）
# ② nasm -f win64 demo.asm -o demo.obj
# ③ GoLink /entry main /console demo.obj msvcrt.dll kernel32.dll /fo demo.exe
```

### 4. 验收示例

```powershell
cargo run --release -- demo.jy     # 完整构建出 demo.exe
.\demo.exe                          # 输出：120
```

`demo.jy`（阶乘，含递归调用）：

```jy
// 阶乘示例（【简言】验收用例）
整数64 阶乘 整数64 n：
    如果 n 小于等于 1：
        返回 1
    返回 n * 阶乘(n - 1)

整数64 结果 = 阶乘(5)
打印 结果
```

## 二、语言规范（第一版实际实现）

### 关键字（全中文，大小写敏感，全字匹配）

`如果` `否则` `当` `函数` `返回` `打印` `导入` `真` `假` `空`
`跳出` `跳过` `重复` `次` `不换行`
另有声明语句保留字 `设`、`为`。

### 基本规则

1. **缩进即块**：固定 **4 空格 = 1 层缩进**，不用花括号，换行分隔语句。
   缩进错误（制表符、非 4 的倍数、缩回不到的层级）直接报【缩进错误】。
2. **顶层直接写语句**：编译器自动把顶层语句包裹进入口 `main`，不必手写 main。
3. **注释**：`//` 直到行尾。

### 变量与赋值

```jy
设 年龄 为 25              // 声明（类型由右侧推断）
整数 结果 = 阶乘(5)        // 显式类型声明
布尔 及格 = 真             // 布尔类型（底层为 1/0）
结果 = 120                 // 普通赋值
结果 += 10                 // 复合赋值：+= -= *= /= %=
```

类型（推荐写法）：`整数`（64 位有符号整数）、`小数`（double）、`布尔`、
`字符串`、`空`（仅作返回类型）。
兼容别名：`整数64`=整数，`整数32`、`浮点数64`/`浮点64`/`小数64`=小数。
动态类型：整数与浮点之间自动转换；**字符串与数值之间不能直接赋值/传参**
（拼接时可用 `+` 自动转字符串）。

### 函数

```jy
函数 返回类型 函数名(参数列表)：      // 推荐写法（v0.3 起）
    缩进语句块

返回类型 函数名 参数列表：            // 旧写法（兼容保留）
    缩进语句块
```

- 参数：`类型 参数名, 类型 参数名, ...`，支持递归与前置引用（调用写在定义前），
  编译期校验参数数量，不支持重载；
- `返回 表达式`；返回类型为 `空` 的函数不允许 `返回` 带值。

### 条件与循环

```jy
如果 条件：
    语句块
否则如果 条件：
    语句块          // 可连续多个（语法糖，展开成嵌套 如果）
否则：
    语句块

当 条件：
    循环体          // while 循环
    跳出            // 立即退出循环
    跳过            // 跳过本次迭代剩余部分

重复 N 次：         // 计数循环（N 为表达式，循环前求值一次）
    循环体
```

### 打印

`打印 表达式, 表达式, ...`：**多个参数同一行依次输出（无分隔符），末尾换行**；
0 个参数只输出一个换行。括号可写可不写：`打印(1, 2)`、`打印 (1, 2)`、
`打印 1, 2` 完全等价。结尾加 `不换行` 取消末尾换行。

```jy
打印 "结果是 ", 120, "！"        // → 结果是 120！
打印 "总分：" + 总和              // 字符串 + 数值：自动转字符串再拼接
打印 "进度：", 1, 2 不换行        // 输出后不换行，可与下一条 打印 接同一行
```

整数/布尔按十进制数字打印，字符串原样输出，浮点按 `%g` 打印。
字符串字面量支持转义：`\n` `\t` `\r` `\0` `\\` `\"`。
底层调用 `msvcrt.dll` 的 `printf`（GoLink 自动导入，无需导入库）。

### 导入

`导入 "文件名.jy"`：**编译期文本拼接**（类似 C 的 `#include`），不是模块隔离；
路径相对当前文件解析；支持递归导入、循环导入检测（报【循环导入】）；
跨文件出现同名函数/变量会被报【符号重复定义】。

### 运算符（优先级从高到低）

| 优先级 | 运算符 | 说明 |
| ---- | ---- | ---- |
| 1（最高） | `-`（取负） `!`/`！`（非） | 一元 |
| 2 | `*` `/` `%` | 乘除取余（`%` 仅整数） |
| 3 | `+` `-` | 加减 / 字符串拼接（任一操作数为字符串时） |
| 4 | `>` `<` `>=` `<=` `==` `!=` | 比较（不支持连续比较；六种都支持字符串，字典序） |
| 5 | `&&`（与/且） | 逻辑与，短路求值 |
| 6（最低） | `\|\|`（或） | 逻辑或，短路求值 |
| — | `=` `+=` `-=` `*=` `/=` `%=` | 赋值/复合赋值（语句，不是表达式） |

**中文比较词别名**（与符号形式等价）：`小于` `大于` `小于等于` `大于等于` `等于` `不等于`。

**中文逻辑词别名**：`与`/`且` → `&&`，`或` → `||`，`非` → `!`。

**字符串运算**：`+` 拼接（另一侧为数值/布尔时自动转字符串）；
六种比较（两侧都必须是字符串，按字典序）。其余运算符不适用于字符串。

**尚未实现**：函数重载。

### 书写友好性

- 全角标点自动归一化：`：`→`:`，`，`→`,`，`（）`→`()`，`！`→`!`，全角空格按空格处理；
- **中文弯引号归一化**：`“ ”` 与 `"` 等价，都可作字符串定界符（可混合配对）：
  `打印 “Hello, World!”`；
- 类型别名：`整数`/`整数64`、`小数`/`浮点数64`/`浮点64`/`小数64` 各自等价；
- 标识符允许中文（含数字与下划线，不能以数字开头，不能与关键字重名）。

## 三、错误系统

全部报错为**中文**，带 `文件:行:列`、错误类别与出错行下划线提示，绝不抛 Rust 原生 panic：

```
错误[语义]: demo.jy:3:5: 使用了未定义的变量『乙』（请先使用 设 变量名 为 表达式 声明）
    打印 乙
        ^
```

| 类别 | 示例 |
| ---- | ---- |
| 词法错误 | 无法识别的字符、字符串未闭合、整数越界、缩进错误 |
| 语法错误 | 缺少 `：`、缩进块缺失、`否则` 位置不对、一行多语句 |
| 语义错误 | 变量未定义、未定义的函数、参数数量不匹配、符号重复定义、字符串参与不支持的运算 |
| 工具链错误 | 找不到 nasm/GoLink、汇编/链接失败（附原始输出） |
| 输入输出错误 | 源文件不存在、无法写出产物 |

导入展开维护“行来源表”，被导入文件里的错误也能定位到**真实文件与真实行号**。

## 四、项目结构

```
jian/
├── Cargo.toml            # 零第三方依赖
├── demo.jy               # 验收用例（阶乘，输出 120）
├── examples/             # 更多示例（变量/打印、条件循环、浮点函数、导入）
├── tests/
│   ├── cli.rs            # 集成测试：完整编译闭环 + 错误诊断
│   └── fixtures/         # 错误用例（未定义变量、缩进、参数不匹配、重复定义）
├── tools/                # 约定放置 nasm.exe 与 GoLink.exe（git 忽略）
└── src/
    ├── main.rs           # 入口：参数解析、三种模式分派、panic 兜底
    ├── ast.rs            # 抽象语法树定义
    ├── error.rs          # 中文诊断系统（行来源映射、错误打印）
    ├── import.rs         # 导入预处理（文本拼接 + 循环检测 + 行来源表）
    ├── lexer.rs          # 词法分析（缩进记号、中文比较词别名、全角归一化）
    ├── parser.rs         # 语法分析（递归下降、语句级错误恢复）
    ├── semantic.rs       # 语义分析（符号表、未定义/重复/参数数量检查）
    ├── codegen.rs        # 汇编生成（NASM win64、栈帧、调用约定）
    └── toolchain.rs      # nasm / GoLink 定位与调用
```

**编译管线**：`main` 依次调用
`import::展开导入 → lexer::切分 → parser::解析 → semantic::分析 → codegen::生成 → toolchain::调用nasm → toolchain::调用golink`。

## 五、汇编输出长什么样

`jianyan -S demo.jy` 生成（节选）：

```nasm
; 由【简言】编译器自动生成的 NASM x86-64 Windows 汇编
bits 64
default rel

section .rdata
    __fmt_int:   db "%lld", 10, 0
    ...

section .text
    extern printf    ; 由 GoLink 从 msvcrt.dll 自动导入
    global main

_jy_fn0:
    push rbp
    mov rbp, rsp
    sub rsp, 32
    mov [rbp-8], rcx      ; 参数 n
    ...
    cmp rcx, rax          ; 比较 n <= 1
    jg .L1                ; 条件不成立 → 跳过
    ...
    call _jy_fn0          ; 递归调用 阶乘(n - 1)
```

设计要点：

- **调用约定**：Windows x64（win64）。整数/指针参数走 `rcx/rdx/r8/r9`，浮点走 `xmm0~xmm3`，
  超出按参数顺序压栈；每次 `call` 前预留 32 字节影子空间，`rsp` 恒 16 字节对齐；
- **变参特例**：Windows x64 变参函数（如 `printf`）要求浮点实参**同时在对应 GPR 中留位副本**
  （`movq rdx, xmm0`），这是本项目的经典踩坑点，已在代码注释中标注；
- **值约定**：整数/布尔/字符串指针 → `rax`，浮点 → `xmm0`；
- **栈帧**：每个变量一个 8 字节槽位（参数在前、局部在后），表达式临时区在帧底，
  帧大小在函数体生成完后统一计算；
- **符号映射**：中文函数名映射为 `_jy_fn0`、`_jy_fn1`……（汇编注释保留原名）；
- **字符串/浮点常量**：统一放 `.rdata`（浮点常量显式 `align 8`）；打印走
  `msvcrt.dll` 的 `printf`；
- **中文路径兼容**：nasm/GoLink 是传统 ANSI 程序，源文件路径含中文时，
  编译器会自动复制到临时目录用 ASCII 文件名完成汇编/链接再搬回。

## 七、已知限制

- 无函数重载；
- **字符串拼接/转换产生的临时串不释放**（教学实现，运行期 malloc 泄漏，
  短小程序无碍；拼接结果可以正常赋值与打印）；
- `重复 N 次` 的次数在进入循环前只求值一次（修改表达式里的变量不影响次数）；
- 整数除零、整除溢出是**运行期**崩溃（idiv 异常），编译期不检查；
- 变量作用域为“整个函数”粒度（无块级作用域），函数名与变量名是两套命名空间；
- `导入` 是纯文本拼接：被导入文件的顶层缩进假设与导入处一致；
- 顶层语句被包裹进 `main`，因此函数之间没有共享的全局变量（参数传递即可）；
- 表达式语句仅允许函数调用；比较运算不支持连续比较（如 `a < b < c`）；
- `%g` 打印浮点：`3.0` 显示为 `3`，`3.14` 显示为 `3.14`；
- 控制台中文显示需要 UTF-8 代码页（编译器已自动 `SetConsoleOutputCP(65001)`）。
